One loading-screen tip for stressed developers and AI coding agents, written for the [make.fun](https://make.fun/bounty/u-ricoxyz-loading-screen-gold-a-tip-in-200-characters-2b1df270) bounty "Loading Screen Gold: A Tip in 200 Characters".

> Tip: if the agent goes quiet, it isn't thinking. It's deciding how to tell you your last two instructions contradicted each other.

`main.ts` (Node 22, stdlib only) writes the tip to `entry.txt` in the output directory. 130 characters, one line.

The joke is aimed at both sides of the keyboard at once: the developer who gave two instructions that cancel each other out, and the agent too polite to say so mid-build.
